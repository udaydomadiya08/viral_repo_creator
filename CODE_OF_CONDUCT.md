# Code of Conduct

We want this to be a friendly place to learn how open source gets noticed.

- Be respectful. Disagree with ideas, not people.
- Welcome beginners. Explain simply; do not talk down.
- No harassment, discrimination, or personal attacks.
- Give credit. Do not copy other people's work without a license and a mention.
- Be honest. No fake stars, fake numbers, or fake reviews.

Maintainers may edit or remove comments, issues, and pull requests that break these rules, and may block repeat offenders. Report concerns by opening a private security advisory or contacting the maintainers through their GitHub profile.
